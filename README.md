## Mise en ligne sur Vercel

1. Placez tous les fichiers dans un dépôt GitHub.
2. Importez le dépôt dans Vercel.
3. Sélectionnez **Other** comme Framework Preset si nécessaire.
4. Aucun Build Command n’est requis.
5. Déployez.

## Lancement local

```bash
python -m http.server 8080
```

Puis ouvrez `http://localhost:8080`.
